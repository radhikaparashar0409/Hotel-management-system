# Hotel-management-system
A comprehensive Hotel Management System designed to streamline room bookings, check-ins, checks-outs, and billing processes.
markdown# Hotel Booking System 

This is a simple command-line based **Hotel Booking System** project built in Python. It allows users to easily manage, book, and check out hotel rooms.

## Features

* **View Rooms:** View a list of all hotel rooms, their price, and availability status (Available/Booked).
* **Book a Room:** Book a room by entering guest details (Name, Age, Phone Number, and Number of Nights).
* **Cancel Booking:** Cancel an existing booking easily by entering the room number.
* **View Bookings:** View details of all currently booked rooms and guest information in one place.
* **Checkout:** Generate the total bill when a guest checks out and change the room status back to Available.

## Technologies Used

* **Language:** Python 3.x
* **Concepts:** Programming Logic, Dictionaries, Functions, and Error Handling (`try-except`)

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project folder:**
   ```bash
   cd Hotel-management-system
   ```

3. **Run the Python file:**
   ```bash
   python main.py
   ```

## Project Menu Interface
When you run the program, you will be presented with the following options:
1. View Rooms
2. Book a Room
3. Cancel Booking
4. View Bookings
5. Checkout
6. Exit
